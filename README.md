# Bangalore Smart Metro

A modern web application for navigating and managing the Bangalore Metro transit system.

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm

### Installation

1. Clone the repository and navigate to the project directory.
2. Install the dependencies:
   ```bash
   npm install
   ```

### Development

Start the development server (runs the backend Express server with TSX and hot reloading):
```bash
npm run dev
```

### Production Build

To build the React frontend and bundle the Express server:
```bash
npm run build
```

Then start the production server:
```bash
npm run start
```
